# Eternal Terminal open-issue triage

Reviewed 2026-09-17 against the 94 issues currently open in `MisterTea/EternalTerminal`, the issue discussions, merged pull requests, and the current source tree. This is a recommendation document only; no GitHub issue was changed.

## Triage policy

- **Work on it**: reproducible bug, security/reliability problem, or a well-scoped improvement worth maintaining.
- **Close**: fixed, answered, obsolete, unsupported, not actionable without information that has gone stale, or better handled outside this repository.
- **Leave open, unworked**: valid idea or external tracking item, but not a current project priority.
- **Duplicate**: consolidate discussion into the named canonical issue.

“Close” does not always mean the original report was wrong. In several cases it means the report concerns a years-old release and no longer provides a useful test case. Before closing a supposedly fixed bug, the closing comment should name the fixing PR/release and invite a fresh issue if it reproduces on the latest release.

2. Consolidate the four true duplicates (#785, #783, #524, #445), preserving any unique reproduction details in the canonical threads.

## Notes and uncertainties

- This is static triage, not runtime verification of every historical platform report. “Fixed” recommendations are based on merged changes that directly match the reported cause, plus current-source inspection.
- #538 and #449 are borderline. A declared supported-platform policy and one current-master cleanup test would make their disposition objective.
- #90’s LocalForward portion is fixed. Its RemoteForward remainder should become a new focused issue only if it is still wanted.
- #485 is the canonical target for one duplicate but is intentionally not a “work now” recommendation.
